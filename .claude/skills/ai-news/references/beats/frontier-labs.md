# Beat: frontier-labs (edition: world)

**What this beat covers.** The labs that set the frontier and what they shipped this week: Anthropic, OpenAI, Google DeepMind / Google, Meta, xAI, Mistral, DeepSeek, Alibaba's Qwen, Moonshot (Kimi), Zhipu, MiniMax, Amazon, Microsoft, Apple. Model releases and deprecations, prices and rate limits, capabilities with the lab's own numbers, product features (apps, agents, coding tools), outages and incidents, usage policies, compute and chip deals with amounts, leadership moves, lawsuits with a filing. Also "other countries": Chinese labs' releases, EU/UAE/Japan/Korea national models when they ship something.

**What counts.** The lab's own post, model card, system card, pricing page, status page or changelog; a court filing; a regulator's page. Press coverage is fine when it adds a number the primary page lacks, but link the primary page too.

**What does not count.** Rumours, "sources familiar", leaked benchmarks, demos on X, hot takes about AGI.
